# Customer Basket Analysis Dashboard

## About the Project

This project is a Customer Basket Analysis Dashboard created using Power BI.

I created this dashboard to explore customer basket data and understand different patterns in the dataset. The dashboard gives a quick overview of customers, basket counts, customer age, and product-related information.

While working on this project, I focused on creating a simple and interactive dashboard that makes the data easier to understand.

## What I Did

In this project, I:

- Explored and cleaned the dataset
- Created KPI cards to display important information
- Analyzed basket counts based on gender
- Created a trend analysis using the available date data
- Analyzed customer age information
- Analyzed basket counts for different products
- Added a date slicer to make the dashboard interactive

## Dashboard Highlights

The dashboard shows:

- Total Basket Count
- Total Customers
- Average Customer Age
- Average Basket Count
- Basket Count by Gender
- Basket Count Trend
- Customer Age Distribution
- Product-wise Basket Count
